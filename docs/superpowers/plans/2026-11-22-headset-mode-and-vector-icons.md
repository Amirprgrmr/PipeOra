# برنامه اجرایی ارتقای UI/UX و مدیریت حالت هدست بلوتوث (میکروفن مکالمه در برابر کیفیت موسیقی)
## AM Audio Control | نسخه 1.1.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** جایگزینی کامل تمامی استیکرها و ایموجی‌ها با آیکون‌های وکتور اختصاصی SVG، ارتقای استاندارد بصری رابط کاربری به سطح دسکتاپ پریمیوم لینوکس، و پیاده‌سازی سوئیچ تخصصی و شفاف حالت هدفون‌های بلوتوث (به‌ویژه **QCY T13 ANC2**) برای انتخاب آگاهانه میان **«حالت موسیقی باکیفیت (A2DP بدون میکروفن)»** و **«حالت مکالمه (HFP با میکروفن فعال هدست)»**.

**Architecture:**
1. **سیستم وکتور آیکون (SVG Icon Library):** ساخت کتابخانه آیکون‌های برداری بهینه‌شده با استانداردهای طراحی آزاد دسکتاپ و پیاده‌سازی کلاس `IconHelper` جهت مدیریت کش، مقیاس‌پذیری و بارگذاری آیکون‌ها در فریم‌ورک Qt 6.
2. **مدیریت حالت هدست در Profile Manager:** متدهای اختصاصی `get_headset_mode` و `set_headset_mode` جهت تشخیص دقیق وضعیت فعلی (A2DP یا HFP) کارت‌های صوتی بلوتوث و سوئیچ مستقیم بدون نیاز به درگیری کاربر با نام‌های فنی کارت‌ها.
3. **کامپوننت اختصاصی `HeadsetModeCard`:** طراحی یک کامپوننت سگمنت‌شده مدرن با دو کارت تعاملی:
   - حالت استریو باکیفیت (A2DP): برای موزیک، گیم و ویدیو با کیفیت صدای ۴۸ کیلوهرتز و کدک AAC/SBC (میکروفن هدفون غیرفعال).
   - حالت مکالمه (HFP Headset): برای جلسات، تماس‌های تلگرام و میت با فعال‌سازی کامل میکروفن هدفون (همراه با برچسب هشدار تغییر فرکانس صوتی).
4. **بازطراحی و پولیش UI/UX:** اعمال استانداردهای طراحی `ui-ux-pro-max` و `frontend-design` بر روی سایدبار، اسلایدر ولوم، کارت‌های دستگاه‌ها و تمام صفحات، با حذف ۱۰۰٪ ایموجی‌ها و استفاده از استایل‌های مدرن با حاشیه‌های ظریف و انیمیشن‌های مینیمال.

## Global Constraints

- **سازگاری با پایپ‌وایر و بلوتوث:** سوئیچ میان A2DP و HFP باید مستقیماً از طریق `pactl set-card-profile` انجام شده و نتیجه در کارت خروجی و داشبورد بازتاب یابد.
- **شفافیت اثر برای کاربر:** کاربر باید دقیقاً متوجه شود که با انتخاب حالت مکالمه، میکروفن هدفون فعال می‌شود اما کیفیت صدای خروجی به مونو/مکالمه تبدیل می‌گردد؛ و با بازگشت به حالت استریو، کیفیت عالی بازمی‌گردد.
- **ممنوعیت استفاده از استیکر/ایموجی:** تمامی نمادهای گرافیکی برنامه باید فایل‌های واقعی برداری SVG در مسیر `app/resources/icons/` باشند.
- **حفظ ۱۰۰٪ راست‌چین (RTL) و خوانایی فونت:** استفاده از فونت سیستم (وزیرمتن یا نوتو) با مقیاس‌بندی دقیق.
